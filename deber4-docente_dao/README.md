# Deber 4 - Docente DAO

## Descripción

Implementación del patrón DAO para la entidad Docente utilizando Go y SQLite.

## Tecnologías

- Go
- SQLite
- github.com/glebarez/sqlite

## Evidencia de ejecución

Al ejecutar:

```bash
go run main.go
```

Se obtuvo como resultado:

- Conexión exitosa a SQLite.
- Inicialización de la base de datos.
- Creación de la tabla `docentes`.
